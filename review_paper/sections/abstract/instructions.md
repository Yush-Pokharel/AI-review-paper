# Section Instructions: Abstract

## Agent Rules
- Do NOT write this until ALL other sections are drafted.
- Must be self-contained (readers only see this first).
- Include: purpose, methods (databases, criteria), key findings (architecture comparison, dataset trends), conclusion.
- Reference `direction.md` and `outline.md` for scope.

## Template Structure
1. Background (1 sentence).
2. Objective / Scope (1-2 sentences).
3. Methodology summary (2-3 sentences — mention PRISMA, databases).
4. Key findings (3-5 bullet-style sentences — architectures, datasets, evaluation trends).
5. Conclusion / Impact (2 sentences).

## Pushback Points for Agents
- If abstract claims results that are not yet in sections, flag in `improvement_flags.md`.
- If abstract is too long (>250 words for structured review), trim.
- Ensure base paper is cited if relevant, but don't over-cite it.
