# Section Instructions: Conclusion

## Agent Rules
- Do NOT introduce new studies or data here.
- Summarize: (1) What was reviewed (scope), (2) Key findings (architecture comparison, dataset trends, evaluation gaps), (3) Main limitations (of the review itself — not just studies), (4) Contribution statement.

## Structure (Suggested)
1. Restate purpose (1 paragraph).
2. Key findings summary (1 paragraph — reference sections by number).
3. Review limitations (1 paragraph — screening limitations, language bias, database coverage).
4. Final contribution / closing statement (2-3 sentences).

## Pushback Points
- If conclusion claims findings that differ from sections 4-9, fix the sections, not the conclusion.
- If the base paper is cited, clarify whether this review supports, extends, or challenges its conclusions.
