# Section Instructions: Datasets

## Agent Rules
- Extract from studies: dataset name, size (images), annotation type (bbox, polygon, pixel mask, point), waste categories covered, geographic diversity, image resolution, public/private.
- Create a master comparison table.

## Required Columns for Table
Dataset Name | Size (Images) | Annotation Type | Waste Categories | Geographic Region | Resolution | Availability (Public/Private)

## Pushback Points
- If datasets lack geographic diversity (e.g., mostly from Europe/US), flag this as a limitation.
- Note whether underwater waste datasets exist — if very few, this is a major gap.
- Check if base paper's dataset is included and how it compares.
