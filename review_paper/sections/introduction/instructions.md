# Section Instructions: Introduction

## Agent Rules
- Read `base_published_paper/main.tex` before drafting to match tone/style.
- Use a narrative arc: Problem (river pollution / waste accumulation) -> Current Monitoring Gaps -> Computer Vision Promise -> Deep Learning Revolution -> Review Purpose.

## Required Components
- **Diagram reference**: Mention river pollution diagram (to be created or referenced from base paper). Suggest figure caption: "Figure 1: Impact of river pollution and manual monitoring limitations."
- **Why computer vision?**: Contrast manual inspections (slow, expensive, subjective) with automated detection (scalable, continuous, objective).
- **Review contribution**: What does this review add that the base paper (and existing surveys) does not? (Example: first to compare underwater cameras + UAV + satellite in one framework; first to analyze transformer performance specifically for waste.)

## Pushback Points
- If the intro does not clearly state the review's unique contribution, rewrite.
- If river pollution is mentioned but not defined (urban vs. rural, freshwater vs. marine), ask human to clarify.
- Ensure the base paper is cited appropriately but not treated as the only prior work.
