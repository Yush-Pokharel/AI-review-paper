# INCLUSION / EXCLUSION CRITERIA

## Inclusion (Must Meet ALL)
- [ ] Study uses computer vision / deep learning for waste/plastic/pollution detection.
- [ ] Study uses image data (UAV, satellite, ground camera, underwater, or similar).
- [ ] Study reports quantitative evaluation metrics.
- [ ] Study is available in full text (English preferred; other languages only if translatable).
- [ ] Study published in a peer-reviewed venue OR reputable conference (if including conferences, note it).

## Exclusion (Meet ANY)
- [ ] Study relies solely on non-image sensors (chemical, acoustic without images).
- [ ] Study is a pure theoretical proposal with no dataset or results.
- [ ] Study is a duplicate of an already included paper (same dataset, same method, same authors within same year — check carefully).
- [ ] Study is a review/survey (unless it provides novel synthesis data — discuss with human; we may include it for context but not for primary results).

## Screening Process (Proposed — PRISMA Flow)
1. **Identification**: Records from database searches + additional sources.
2. **Screening**: Remove duplicates; screen titles/abstracts.
3. **Eligibility**: Assess full texts against criteria above.
4. **Included**: Final set for data extraction.
